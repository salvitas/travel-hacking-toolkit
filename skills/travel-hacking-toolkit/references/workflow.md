# Workflow

1. Ask for route, dates, cabin, travelers, and flexibility if missing.
2. Search cash prices and award options.
3. Pull balances/transfer options if points are involved.
4. Compare by effective cost and booking realism.
5. Present the winner and the tradeoffs.

## Response shape
- Short answer first.
- Then a table for options.
- Then the recommendation.
- Include the math when points are involved.
- If something is blocked by missing data, say exactly what is missing.

## Good default prompts
- Search flights for this route and rank the best options.
- Compare award availability and cash pricing.
- Tell me the best redemption path for my points.
